# s0 - Plain Docker

> **Tag:** `s0`
> Goal: verify the app and database work together before touching Kubernetes.

No k8s here. Docker Compose runs the API and Postgres side by side so you can confirm the app works before introducing cluster concepts.

---

## Start

```bash
cd local
docker compose up -d --build
```

The API is available at `http://localhost:3000`. The frontend is available at `http://localhost:8080`.

## Check the API

```bash
# health check
curl http://localhost:3000/health

# create a user
curl -X POST http://localhost:3000/users \
  -H "Content-Type: application/json" \
  -d '{"name": "Alice", "email": "alice@example.com"}'

# list users
curl http://localhost:3000/users

# get one user
curl http://localhost:3000/users/1

# delete a user
curl -X DELETE http://localhost:3000/users/1
```

## Stop

```bash
docker compose down       # keep the postgres volume
docker compose down -v    # also delete the volume (fresh DB next start)
```
